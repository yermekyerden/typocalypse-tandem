### Summary

- Обсуждалась архитектура приложения: важно обрабатывать данные на сервере для безопасности ключей и предотвращения их утечки.
- Подчёркнута важность правильного формирования запросов и использования токенов для оптимальной работы модели.
- Необходимо создавать шаблоны для запросов, которые будут дополняться инструкциями и дополнительными данными.
- Планируется внедрение системы лимитов для пользователей, чтобы избежать перегрузки сервера.

### Задачи:

- Прочитать и проанализировать текущие задачи, продумать виджеты и компоненты.
- Разработать клиент-серверную архитектуру, включая тестовый сервер для разработки и тестирования.
- Подготовить и обогатить текст запросов с помощью шаблонов и инструкций.
- Реализовать систему лимитов для контроля количества запросов пользователей.

### Другие моменты:

- Использование Retrieval Augmented Generation (RAG) для поиска и передачи основной мысли текста.
- Минимизировать шум в тексте для повышения качества ответов модели.
